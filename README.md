# Calculator
<p>A clean, functional four-function calculator built purely with HTML, CSS, and JavaScript. A foundational project for mastering DOM manipulation and basic application logic. It handles standard arithmetic operations and features a clear display for user input and results. A great showcase of CSS Flexbox and JS event handling.</p>
