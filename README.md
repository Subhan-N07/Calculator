## 🎯 Project Objectives

- **⚡ Instant Processing:** Zero-lag input tracking for standard arithmetic operations.
- **📱 Responsive Layout:** Fluid container architecture optimized for desktop, tablet, and mobile displays.
- **🎨 Modern Aesthetic:** High-contrast layout with distinct actionable elements for improved accessibility.
- **🧩 Pure Frontend Execution:** Fast rendering performance with isolated, zero-dependency computation logic.

---

## 🛠️ Tech Stack

- **Structure:** HTML5 (Semantic document architecture)
- **Styling:** CSS3 (Flexbox/Grid structure, smooth interactive hover transitions)
- **Engine:** Vanilla JavaScript (Dynamic DOM manipulation, evaluation matrices, event handling)

---

## ⚙️ Core Operations

```text
Button Press/Key Stroke ──> Event Interception ──> String Validation ──> Math Evaluation ──> Screen Update
```

1) Arithmetic Matrix: Handles standard addition, subtraction, multiplication, and division arrays.

2) Display Controllers: Includes clear (C) actions and backspace corrections to easily drop elements.

3) Edge-Case Parsing: Implements parsing guardrails to handle division by zero errors cleanly.

## 🚀 Getting Started

Follow these steps to run the calculator application locally:

### 1. Installation
Clone the codebase structure using git commands:
```bash
git clone [https://github.com/Subhan-N07/Calculator.git](https://github.com/Subhan-N07/Calculator.git)
cd Calculator
```

### 2. Execution
Since the application uses standalone client assets, no complex background servers or framework installation layers are necessary. 

- **Option A:** Double-click the file named `index.html` inside your explorer menu to open it instantly.
- **Option B:** Serve the application via the VS Code extension **Live Server** to run it on a local port.
